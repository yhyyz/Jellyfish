`v0.5.0` 在 v0.4.0 剧情带货首发的基础上完成 P2 阶段，把链路从「跑通」推进到「生产可用」：
公式库扩到 12 条（含 6 国际公式），新增 27 条模式 seed（10 hook + 5 CTA + 12 archetype），合规 profile 扩到 3 个（cn_mainland_default / cn_mainland_health / overseas_default），以及 3 个 P2 LLM Agent、4 个 P2 task_kind、12 个新 API 端点和 6 个新前端页面/组件。变体支持一键克隆 + champion 标记，批量生成走 slow 队列一次性入队 1–10 个变体。

## Highlights

- 🌍 **+6 国际公式**：Hero's Journey / Pixar Story Spine / 3-Act / SCQA / StoryBrand SB7 / PAS（公式总数 6 cn + 6 global = 12）。
- 📚 **27 模式库**：10 钩子模式 + 5 CTA 模式 + 12 品牌人格 archetype（tonethief 词汇表）启动时自动 seed。
- 🎭 **3 个 P2 Agent**：HookWriter / CTAWriter / ArchetypeVoiceRewriter，含结构保留 validators。
- 🔁 **A/B 变体管理**：一键克隆 + Champion 标记（同 chapter 内仅一个 champion）。
- ⚡ **批量生成**：一次性入队 1–10 个变体，走 slow 队列，超时 7200s。
- ⚖️ **+9 合规规则**：新增 `cn_mainland_health`（健康类专项）和 `overseas_default`（海外默认）2 个 profile，规则总数从 8 → 17，profile 总数 1 → 3。
- 🎨 **6 个新前端页面/组件**：公式库浏览页、合规中心、3 个 selector、变体克隆/champion UI。

## Added

### 数据模型层 (Wave 11)

- 新增枚举：`BrandArchetype`（12 值）、`ToneDimension`（10 维），位于 `app/models/enums/` 和合并的 `app/core/contracts/story.py`（commit `4bb1345`）。
- 新增 3 张表：`hook_patterns` / `cta_patterns` / `brand_archetypes`，对应 alembic `0007`（commit `a87b45f`）。
- 新增 27 条系统级 seed：10 钩子模式 + 5 CTA 模式 + 12 品牌人格 archetype（commit `1e8b475`）。
- 新增 6 条国际公式：Hero's Journey、Pixar Story Spine、3-Act、SCQA、StoryBrand SB7、PAS / BAB（commit `0895303`）。
- 新增 2 个合规 profile：`cn_mainland_health`（健康类专项）、`overseas_default`（海外默认），共 9 条新规则（commit `9483962`）。

### Agent / Worker (Wave 12)

- `HookWriterAgent` + `ShotHook` / `HookWriteVars` 契约（commit `8c8c6e9`），超时 180s。
- `CTAWriterAgent` + `CTAText` / `CTAWriteVars` 契约（commit `2a5b340`），超时 120s。
- `ArchetypeVoiceRewriterAgent` + `validate_structure_preserved` + `validate_words_to_avoid` validators（commit `450431d`），超时 600s。
- 4 个 P2 task_kind：`hook_writer` / `cta_writer` / `archetype_rewrite` / `story_video_batch_generate`（slow 队列，超时 7200s）。
- 4 个新 worker executor，全部在 `task_executor_registry` 注册（commit `2d73499` + `860b09f`）。

### API 端点 (Wave 14)

- `POST /api/v1/studio/story-variants/{id}/clone`（变体克隆）。
- `PATCH /api/v1/studio/story-variants/{id}/champion`（champion 标记，单 chapter 唯一）。
- 来源：commit `1d89126`。
- `POST /api/v1/commerce/story-batches`（批量生成入口，1–10 个变体），commit `860b09f`。
- `POST /api/v1/studio/products/{id}/images/generate`（商品图生成），commit `145e776`。
- `GET /api/v1/studio/hook-patterns` + `/{id}`（read-only）。
- `GET /api/v1/studio/cta-patterns` + `/{id}`（read-only）。
- `GET /api/v1/studio/brand-archetypes` + `/{id}`（read-only）。
- 模式库 read-only API 来自 commit `c59fa4a`。

P1 22 + P2 12 = 34 个 commerce 端点。

### 前端 (Wave 13)

- `/commerce/formulas` 公式库浏览页（12 公式 + 详情 Drawer + 区域 filter），commit `074fce0`。
- `/commerce/compliance` 合规中心（3 tabs：profiles / findings / rules viewer），commit `7b5902a`。
- 3 个新 selector 组件：`HookPatternSelector` / `CTASelector` / `ArchetypeVoiceSlider`，commit `6227bf9`。
- `VariantList` + `VariantCloneModal` 加入 StoryWorkbench（A/B 管理 UI）。
- MainLayout「🛍️ 剧情带货」submenu 扩展为 5 项：商品库 / 剧情项目 / 公式库 / 合规中心 / 任务中心入口。

### 测试覆盖 (Wave 11–15)

- 约 280 个新增单元/服务测试，覆盖 W11–W14 的数据模型、Agent、Worker、API。
- 1 个新 E2E：`backend/tests/test_commerce_batch_e2e_smoke.py`，覆盖批量生成全链路。

- `bootstrap_async_state` 编排顺序扩展为：`prompts → formulas → compliance → hook_patterns → cta_patterns → brand_archetypes`，按依赖顺序固化。
- `_PROMPT_CATEGORY_ZH` 仍保持 v0.4.0 W7-Fix 补齐的 12 条 commerce category 中文映射，本版本未再修改。
- `test_story_formulas_api.py` 断言更新：6 → 12 总公式数（W14-Fix，commit `a4193ee`）。
- 前端 OpenAPI generated client 已按 P2 W14 端点重新生成（commit `c9c365a`）。

## Fixed

- W14-Fix：`test_story_formulas_api.py` 因 W11-T1 加 6 国际公式而漏更新断言（commit `a4193ee`）。
- W11–W14 阶段并发 commit 在 `task_registry.py` / `api/v1/__init__.py` / `App.tsx` 上的合并冲突全部按单批 commit 化解，保证 race condition 不留逻辑空洞。

## Breaking Changes

无。P2 全部为附加内容，不修改 P1 已有接口、字段、状态语义。
现有 `drama` / commerce P1 链路行为保持完全一致。

## Deprecations

无。

## Security

- `pyahocorasick`（BSD-3 license）继续作为合规扫描的核心引擎，依赖未变更。
- `ApiKeyQuota` 表保持空 holder 状态，将在 P3 启用 partner API 时使用。

- 预先存在的 13 个 envelope-shape (`meta: None`) 测试失败，与本次 release 无关，将在后续清理。
- 预先存在的 3 个 collection error（`test_video_capabilities` / `test_script_extract_cache` / `test_script_processing_async_api`），与本次 release 无关。

## Migration Guide

### 步骤 1 — 拉取最新代码并安装依赖

```bash
git pull
cd backend && uv sync
cd ../front && pnpm install
```

### 步骤 2 — 数据库迁移

```bash
cd backend && uv run alembic upgrade head
```

预期：alembic `0007` 应用，新增 `hook_patterns` / `cta_patterns` / `brand_archetypes` 3 张表。

### 步骤 3 — 重启服务

启动时 `bootstrap_async_state` 自动 seed：

- 27 条模式 = 10 hook + 5 CTA + 12 archetype
- 6 条新国际公式（叠加 P1 6 条 cn 公式 = 12 条）
- 2 个新合规 profile（叠加 P1 1 个 = 3 个 profile）

### 步骤 4 — 验证

- `GET /api/v1/studio/story-formulas` 应返回 **12 条**。
- `GET /api/v1/studio/hook-patterns` 应返回 **10 条**。
- `GET /api/v1/studio/cta-patterns` 应返回 **5 条**。
- `GET /api/v1/studio/brand-archetypes` 应返回 **12 条**。
- `GET /api/v1/studio/compliance/profiles` 应返回 **3 条**（`cn_mainland_default` / `cn_mainland_health` / `overseas_default`）。

## Rollback Notes

如需回退到 `v0.4.0`：

```bash
cd backend && uv run alembic downgrade 0006
git checkout v0.4.0
```

注意：

- alembic `0007` downgrade 后 `hook_patterns` / `cta_patterns` / `brand_archetypes` 3 张表 drop，27 条 seed 数据丢失。
- 已生成的 `StoryVariant.archetype` / `hook_pattern_id` / `cta_pattern_id` 字段是字符串外键，rollback 后字符串仍保留在 `story_variants` 表中，但失去 lookup 目标；P1 兼容路径（仅依赖 cn 公式 + cn_mainland_default profile）继续可用。
- 升级前建议 `mysqldump` 备份。

## Notes for Contributors

- 添加新公式、新 hook 模式、新 CTA 模式、新 archetype 时，优先扩展 `bootstrap_builtin_*` seed，不要手动 INSERT，避免 bootstrap 重启时冲突。
- `ArchetypeVoiceRewriterAgent` 改写后必须经过 `validate_structure_preserved`，这是 P2 的结构保护契约，不能绕过。
- `task_executor_registry` race condition 通过单批 commit 化解（W12-T4 / W14 教训），后续新增 task_kind 时建议在同一 commit 内同时 register + test。
- 状态语义保持「`shot.status`（信息确认） / runtime task status / `video-readiness`」三类分离不变；批量生成只影响 runtime 任务状态，不写 `shot.status`。
- AGENTS.md rule 4（api/service 分层） / rule 9（contracts 集中）继续适用，commerce 跨层 DTO 全部在 `app/core/contracts/story.py`。
