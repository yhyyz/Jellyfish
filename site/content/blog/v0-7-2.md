`v0.7.2` 是 v0.7.1「安全加固」之上的**小修小补 + 长尾清债**版本。本版本聚焦五件事：把 W32-followup-2 上线后 manual QA 在浏览器实测发现的 `VITE_API_BASE_URL` 双 `/api` 404 缺口补完、把 W31 sub-agent 披露的 antd Slider API 升级路线显式登记、把 W32-followup-2 之后已无消费者的 `useAppStore.user` 字段连同 hardcode `'Admin / 系统管理员'` 占位一并删除、把 `vite build` 主 vendor chunk > 500KB warning 通过 `manualChunks` 拆分大幅缓解、把 v0.6.0 标 deprecated 的 `chapter_timeline_export` task_kind 提前于原计划 v0.8.0 删除（W31 BGM/SFX 兼容窗口闭合）。alembic 链**保持** v0.7.1 末态 `0023` 不变（v0.7.2 不动 schema）。

升级到 v0.7.2 是**强烈推荐**的：它是 v0.7.1 的清债包，涉及一项 breaking change（`chapter_timeline_export` 删除）+ 一项前端 state 收口（`useAppStore.user` 删除）。其它修改对运行时是兼容增强（防呆 strip / 注释升级 / 构建产物拆分）。

## Highlights

- **Manual QA Bug E 防呆**：`VITE_API_BASE_URL` 末尾 `/api` 自动 strip，避免与 generated client 已有 `/api` 前缀拼成 `http://host/api/api/v1/...` 双 `/api` 404 链路。
- **R-P5-8 清债收口**：W32-T-fixture / W32-T-fixture-followup / R-P5-8 三个 wave 的 alembic head 漂移 / FileUsageKind 总数 / video chain dispatch 计数 / dinov2 sidecar 默认 skip 共 11+ 个 fixture / 计数 case 已在 `64cf062` 末态全部修复，本版本基于该末态展开。
- **前端 state 收口**：`useAppStore.user` / `setUser` 删除，user state 统一由 `AuthContext` 单一源持有；hardcode `'Admin / 系统管理员'` 占位彻底退出运行链路。
- **frontend bundle 优化**：`vite.config.ts` 加 `manualChunks` 拆 `antd` / `charts` / `react-vendor` / `i18n` / `tanstack` 5 类 vendor chunk；主 `index` chunk 从 monolithic 降到 258 KB（gzip 79 KB），各 vendor 独立缓存。
- **Breaking — `chapter_timeline_export` 删除**：v0.6.0 标 deprecated → 原计划 v0.8.0 删，因 W31 BGM/SFX 已 ship 兼容窗口闭合，提前到 v0.7.2 删除。章节级合成统一走 `chapter_av_export`（W19 落地，W31 加 BGM/SFX）。
- **antd Slider 升级路线显式登记**：W31 sub-agent 披露 antd 5.10 `onAfterChange` → 5.12+ `onChangeComplete` 命名变迁；当前 antd `^5.10.0` 保留 `onAfterChange`，docstring + 测试注释登记升级路线，避免后续维护者漏改。

## Fixed

- **W32-T-fixture（commit `80f394a` / `a684c6b`，v0.7.1 base 之上落地）**：W30 / W31 / W29 alembic 测试 fixture 兼容 `0021` / `0023` head；voice_pack_clone fixture 修补。
- **R-P5-8（commits `d457b0f` / `64cf062`）**：`0008/0009/commerce` alembic 测试 head 漂移修复；`FileUsageKind` 总数计数对齐（v0.7.2 commit 5 之后变更，详见 Changed）；video chain dispatch 4 case 修复；dinov2 sidecar 集成测试默认 skip（需 `DINOV2_INTEGRATION=1` 启用）。
- **Manual QA Bug E（本版本 commit `d7d1001`）**：`services/openapi.ts` 抽出 `normalizeApiBase()`，`VITE_API_BASE_URL` 末尾 `/api` 或 `/api/` 自动 strip；vitest 5 case 覆盖 strip / 保留 / 边界形态；`.env.example` 加注释说明推荐填后端根 URL。
- **前端 build chunk size warning（本版本 commit `12dc823`）**：`vite.config.ts` 加 `rollupOptions.output.manualChunks`，主 vendor 不再单文件超 2.8MB；`antd` 与 `charts` 各自独立 chunk（仍 >500KB 是库自身体积下限），主业务代码改动不再让 vendor 缓存失效。

## Changed

- **`useAppStore.user` 字段清理（commit `a92c8df`）**：`store/useAppStore.ts` 删除 `UserInfo` / `user` / `setUser`；`pages/Settings.tsx` 改读 `useAuth().user`，nickname / role 改为 read-only 展示（编辑能力未对接后端 user 管理 API）；`MainLayout.tsx` / `ApiKeysPage.tsx` 注释同步收口说明。
- **vite manualChunks 拆 5 类 vendor（commit `12dc823`）**：`antd` (antd + @ant-design/icons) / `charts` (@ant-design/charts) / `react-vendor` (react + react-dom + react-router-dom) / `i18n` (i18next + react-i18next + browser-languagedetector) / `tanstack` (react-query + devtools)。
- **antd Slider docstring + 测试注释升级路线登记（commit `1b6f9a7`）**：`AVPreviewPanel.tsx` 的 ducking / sfx_offset 滑块两处 docstring 显式说明 5.10 `onAfterChange` vs 5.12+ `onChangeComplete` 命名差异与升级时机；`AVPreviewPanel.test.tsx` case 12 / case 17 注释同步登记。
- **`FileUsageKind` 删除 `chapter_master_video`**：随 `chapter_timeline_export` 一起删除；产物用途由 `chapter_master_dubbed`（W19 chapter_av_export 输出）单独表达。
- **dinov2 sidecar 集成测试默认 skip**：现有测试通过 `DINOV2_INTEGRATION=1` 环境变量启用，避免 CI 默认跑链路打到外部 sidecar。

## Breaking Changes

1. **`chapter_timeline_export` task_kind 删除（commit `f7ea272`）**
   - **背景**：v0.6.0 标 deprecated → 原计划 v0.7.0 删，因 W31 BGM/SFX 兼容窗口未关延期到 v0.8.0；v0.7.2 W31 已 ship 兼容窗口闭合，提前删。
   - **影响**：
     - HTTP 路由 `POST /api/v1/studio/chapters/{chapter_id}/timeline/export` 删除（v0.6.0 之前的客户端调用会收到 404）；
     - `task_kind="chapter_timeline_export"` 注册项从 `task_executor_registry` 移除；
     - `FileUsageKind.chapter_master_video` 枚举值删除（如果 DB 中有历史 `FileItem.usage_kind="chapter_master_video"` 数据，反序列化会失败，需迁移到 `chapter_master_dubbed` 或保留为 raw 字符串字段）；
     - frontend `VideoEditor.tsx` 的"导出成片"按钮被替换为"导出成片入口已迁移"提示，引导用户走分镜工作室 `AVPreviewPanel` 的"立即生成成片"。
   - **修复路径**：调用方使用 `chapter_av_export` task_kind；触发入口为分镜工作室 `AVPreviewPanel` 的"立即生成成片"按钮。

2. **`useAppStore.user` / `useAppStore.setUser` 字段移除（commit `a92c8df`）**
   - **背景**：W32-followup-2 起 user state 已迁到 `AuthContext`，原 `useAppStore.user` 仅作 hardcode `'Admin / 系统管理员'` 占位兜底，已无运行时消费者。
   - **影响**：第三方插件 / 外部脚本若直接读 `useAppStore.getState().user` 会拿到 `undefined`。
   - **修复路径**：改用 `useAuth().user`（来自 `front/src/contexts/AuthContext`），role 与 username 由后端 `GET /me` 真实返回。

## Deprecations

本版本无新增 deprecation。`JWT_FALLBACK_TO_STATIC=true` 仍维持 v0.7.1 标记的 deprecated 状态，P6 起删除。

## Security

- 本版本无新增安全加固；继承 v0.7.1 的 `jwt_fallback_to_static` 默认禁用 + `BOOTSTRAP_ADMIN_PASSWORD` / `SECRET_KEY` 启动期硬校验。

## Known Issues

- **antd / charts vendor chunk 仍 >500KB**：`pnpm run build` 仍会报 `Some chunks are larger than 500 kB after minification` warning，但已隔离到独立 chunk，不再阻塞主业务 chunk 缓存。后续可在 AnalyticsPage 改 dynamic import() 进一步压缩 charts 加载。
- **antd 升级到 5.12+ 切换 `onChangeComplete` 待办**：当前 antd `^5.10.0`，AVPreviewPanel ducking / sfx_offset 滑块继续用 5.10 命名 `onAfterChange`；升级 antd 时需要同步在 `AVPreviewPanel.tsx` + `AVPreviewPanel.test.tsx` 两处一起切换，docstring 已显式登记。

## Migration Guide

从 v0.7.1 升级到 v0.7.2 的推荐流程：

1. **拉取代码**
   ```bash
   git fetch origin
   git checkout dev   # 或 main
   git pull
   ```

2. **alembic 不需要升级**：v0.7.2 不动 schema，alembic head 仍 `0023`。
   ```bash
   cd backend
   uv run alembic current
   # 期望：0023 (head)，与 v0.7.1 一致
   ```

3. **检查代码无 `chapter_timeline_export` 引用**
   ```bash
   # 业务代码不应再调用以下符号：
   grep -rln "chapter_timeline_export\|ChapterTimelineExportRequest\|chapter_master_video" \
     . 2>/dev/null | grep -vE "node_modules|__pycache__|site/content/blog/v0-6"
   # 命中只能在 site/content/blog/v0-6-0.md / v0-7-0.md 等历史文档里
   ```

4. **frontend rebuild**：`vite.config.ts` 的 `manualChunks` 自动生效，无需配置变更。
   ```bash
   cd front
   pnpm install
   pnpm run build
   # 期望：dist/assets/index-*.js ≈ 258 KB；antd / charts / react-vendor /
   #       i18n / tanstack 各自独立 chunk
   ```

5. **数据迁移检查（仅有历史 chapter_master_video 数据时）**
   ```sql
   -- 若 DB 内确有 file_items.usage_kind = 'chapter_master_video' 行：
   SELECT id, usage_kind, created_at FROM file_items
    WHERE usage_kind = 'chapter_master_video';

   -- 推荐迁移到 chapter_master_dubbed（语义对应章节级最终成片）：
   UPDATE file_items SET usage_kind = 'chapter_master_dubbed'
    WHERE usage_kind = 'chapter_master_video';
   ```
   未跑此迁移的部署，访问历史成片记录时 ORM 反序列化会抛错。

6. **客户端清缓存**：使用 `VITE_API_BASE_URL=http://host/api` 形态的部署在 v0.7.2 之后会自动 strip 末尾 `/api`，无需改 `.env`；如想去除注释带来的歧义，可改填后端根 URL `VITE_API_BASE_URL=http://host`（不带 `/api`）。

7. **重启服务**
   ```bash
   docker compose -f deploy/compose/docker-compose.yml restart backend frontend
   ```

## Rollback Notes

如需回滚到 v0.7.1：

```bash
# 1. alembic head 不变（仍 0023），无需 downgrade

# 2. git revert 6 个 commit（按时序倒序）
git revert <release-note-sha>     # commit 6: docs
git revert f7ea272                # commit 5: chapter_timeline_export 删除
git revert 12dc823                # commit 4: vite manualChunks
git revert a92c8df                # commit 3: useAppStore.user 清理
git revert 1b6f9a7                # commit 2: AVPreviewPanel slider 注释
git revert d7d1001                # commit 1: VITE_API_BASE_URL 防呆
```

注意：commit 5（`chapter_timeline_export` 删除）回滚后，需重新生成前端 OpenAPI client（`pnpm run openapi:update`），否则 `StudioChaptersService.postChapterTimelineExport...` 方法会缺失。

## Notes for Contributors

- `services/openapi.ts` 现在抽出 `normalizeApiBase()` 公共纯函数；后续若新增 BASE 注入路径（如 query string override / cookie 覆盖），统一走该函数。
