`v0.7.0` 是 v0.6.0「视觉生产级」之上的**基础设施补完**版本。本版本一次性整合三阶段产出：P2 W12–W15 收口（钩子 / CTA / archetype agent 测试 + i18n / Celery 审计）、P4 W22–W27 Scale 阶段（StoryOutcome 归因 + Partner API + 多平台导出 + 品牌资产保险柜 + 合规告警 + DINOv2 视觉一致性引擎）、P5 W28–W33 出海与协作能力（4 语言完整 i18n / DashScope CosyVoice 自定义音色 / 项目级字幕覆盖 / BGM·SFX 链路 / 用户体系 + RBAC / 数字人路径调研）。

P5 在 P4 商业化能力之上把"为了赶节奏暂留"的工程债清掉：i18n 从 zh-CN hardcode 升到 4 locale 整树、`VoicePack` 从仅系统级扩到自定义训练、`SubtitleStyle` 从单层系统模板扩到双层 resolver、`chapter_av_export` 从 voice-only 扩到 voice/voice_bgm/full 三档、admin 路径从静态 `settings.api_key` 升级到 JWT + role-based 守卫并保留 2 周 Stage-1 fallback 兼容窗口。alembic 链从 v0.6.0 末态 `0017` 推进到 v0.7.0 末态 `0021`（4 个独立 migration，单 wave 可回滚）。

数字人 / lip-sync 路径仍维持 D10 决策不实装，仅产出 `plans/digital-human-research.md` 调研文档（Sadtalker / D-ID / Wav2Lip 三路径 18 维 comparison matrix + 21 atomic Wave 35+ pre-decomposition）。

## Highlights

## Breaking Changes

- **`alembic head` 从 `0017_p4_consistency_status_retry` 推进到 `0021_p5_users_rbac`**：
  - 影响范围：所有非首次部署。
  - 升级方式：`cd backend && uv run alembic upgrade head`，幂等可重入；4 个 migration 全部走 `batch_alter_table` 跨 SQLite/MySQL 兼容。
  - 不升级会导致 `voice_packs` / `subtitle_styles` / `chapter_timeline_segments` / `users` 表与 ORM 对不上，启动后任何写路径 500。
- **现有 admin 端点加 `require_admin` 守卫**（commit `324bf81`）：
  - 影响范围：`/api/v1/settings/api-keys/*`（router-level）/ `/api/v1/llm/providers POST·PATCH·DELETE` / `/api/v1/llm/models POST·PATCH·DELETE` / `/api/v1/llm/model-settings PUT` / `/api/v1/commerce/projects/{id}/subtitle-styles POST·PATCH·DELETE`。
  - 不带 token 调 → 401；member token 调 → 403；admin token / Stage-1 fallback token 通过。
  - 兼容路径：临时设 `JWT_FALLBACK_TO_STATIC=true` + 现有 `settings.api_key` 走 Bearer 携带，与 v0.6.0 行为一致；2 周后下线（详见 R-P5-3）。
  - GET 浏览读路径（`/llm/providers GET` / `/llm/models GET` / `/commerce/subtitle-styles GET` 系统模板浏览）不加守卫，向后兼容。
  - `/api/v1/public/*` 仍走 W24 ApiKey middleware scope，**不混 RBAC**。
- **`POST /api/v1/login/access-token` 不在 ApiKeyMiddleware 拦截范围**：与 `/docs` / `/health` 同级 SKIP_PATH；任何部署都可达，无论是否配置 `API_KEY`（commit `d1e201e`）。
- **`v0.6.0 Deprecations` 中标记的 `chapter_timeline_export` 入口**：v0.7.0 **保留**未删除；继续 deprecated；正式删除推迟到 v0.8.0（v0.6.0 release note 已声明删除时点是 v0.7.0，但本版本因 W31 BGM/SFX 链路改动需要确认下游兼容窗口，决议延后）。
- **`SubtitleStyle.project_id` FK + `chapter_timeline_segments` BGM/SFX/ducking 三字段**：现有调用代码不受影响（字段 nullable + 兼容默认值）；OpenAPI generated 类型新增 3 字段，前端 generated client 需要跑 `pnpm run openapi:update`。
- **`VoicePack` 加 5 字段 + `clone_status` 区分自定义/系统行**：existing 系统行 backfill `clone_status='ready'`；现有 `GET /commerce/voice-packs` 路由维持原 schema 不变（系统行视图）；新自定义视图走 `GET /commerce/voice-packs/custom`。

## Deprecations

- `JWT_FALLBACK_TO_STATIC` env 双轨兼容窗口：默认 `true`（保留 2 周兼容现有 dev workflow），≤2 周后默认改 `false`（R-P5-3 风险登记），**v0.7.1** 删除 fallback 分支。
- `BOOTSTRAP_ADMIN_PASSWORD=changeme` 默认值：v0.7.0 启动期 `bootstrap_admin` 写明"生产必须改"；v0.7.1 强制 `.env` 显式赋值，未赋值启动直接 fail-fast。
- `chapter_timeline_export` task_kind（v0.6.0 deprecated 延期）：v0.8.0 删除。
- 旧 `passlib bcrypt` 哈希用户：登录时自动 `verify_and_update` 升级到 argon2；v0.7.x 都兼容；v0.8.0 起 `pwdlib bcrypt` extra 可移除。

## Security

- **密码哈希升级**：`pwdlib argon2` 替代 `passlib bcrypt`（passlib 已废弃 / argon2 OWASP 2023 推荐默认参数）；旧 bcrypt 自动 `verify_and_update` 迁移到 argon2，无需手动数据迁移。
- **JWT 库升级**：`pyjwt` 替代 `python-jose`（python-jose 已废弃）；HS256 + 60 min exp + sub=user.id（不放 role 避免降权后旧 token 仍持 admin）。
- **admin 端点全部加 `require_admin` 守卫**（W32-T7）：之前裸奔的 `/settings/api-keys` / `/llm/*` 写路径 / `/commerce/projects/{id}/subtitle-styles` 写路径现在需要 admin token；GET 浏览读路径保持开放兼容。
- **登录 401 错误消息统一**（用户不存在 / 密码错均返 `Incorrect username or password`）防用户枚举攻击；400 仅用于已知 username + `Inactive user`。
- **`bootstrap_admin` 启动期幂等**：仅当 `users` 表为空时创建首个 admin；启动期 DB 不可用独立 try/except 容错不阻断进程；`BOOTSTRAP_ADMIN_PASSWORD=changeme` 默认值在 logs 显式提示生产必须改。
- **`get_current_user` 每请求查 DB 拿最新 role**：通过 SQLAlchemy identity map O(1) 缓存命中同 session 内不重复 SQL；避免 JWT claims 缓存 role 导致降权延迟。
- **DashScope `voice-enrollment` 远端隔离**：自定义音色样本走 OSS bucket（ACL public-read，仅 `language_hints` Form 字段决定 voice 训练目标语言）；DashScope SDK 走 `asyncio.to_thread` + 全局 `_REGION_SWITCH_LOCK` 串行化避免 `base_http_api_url` 跨 region 竞态。
- **W19b 双引擎事务边界契约延续**：`commerce_export` / `voice_clone_poll` / `subtitle render` 等所有新 worker 严守 commit-then-send_task；service 层显式 `await session.commit()` 后再 `send_task`。
- **`/api/v1/public/*` 与 RBAC 解耦**：W24 ApiKey middleware scope 与 W32 RBAC scope 分别守卫不同子树，避免混淆；公共第三方调用入口仍走 ApiKey 路径不受 RBAC 影响。

## Known Issues

- **AuthContext 当前用 fallback `role='admin'`**：登录后未实际拉取 `/me` endpoint，前端 role 默认推断为 admin；W34+ 加 `/me` endpoint 可恢复真实 role（W32 sub-agent 披露的可观察问题，非阻塞）。
- **BGM/SFX `sfx_offset_ms` 写死 `0`**：`ChapterTimelineSegment` schema 未提供 `sfx_offset_ms` 列，filter spec 默认 0 ms；R-P5-11+ 后续可加 `sfx_offset_ms` 列实现 SFX 相对 segment 起点的偏移控制（W31 sub-agent 披露）。
- **alembic 历史测试 hardcoded head 漂移**：`tests/alembic/test_alembic_0008.py` / `test_alembic_0009.py` head 断言 hardcoded 在 `0011`，与实际 `0021` 漂移（R-P5-8 风险登记中 P5 范围内不修，测试本身用别的 fixture pattern，head 漂移不影响断言主体；标 known issue 提示后续清理）。
- **DINOv2 sidecar integration test 需要外部容器**：本地 / CI 仅跑 `httpx adapter unit + worker offline` cases；完整 sidecar e2e 需要外部 DINOv2 容器（R-P5-9 风险登记，pre-existing 与 v0.6.0 一致）。
- **`FileUsageKind` 总数断言滞后**：W19b 引入新 usage kind 后 pre-existing 测试断言总数未跟进（与 v0.6.0 一致，pre-existing baseline 噪声）。
- **antd `Modal` 在 jsdom 中 close-animation 缓存导致 RTL 测试残留 DOM 节点**：与 W24-T5 同源问题（R-P5-10 风险登记），W30-T5 / W32-T10 modal RTL 测试都加 `await waitFor(() => expect(modal).not.toBeInTheDocument())` 兜底；不影响实际功能。
- **W19b ASR `keep_native` 路径仍依赖 r2v 输出含可识别人声**：纯环境音 r2v 输出会得到空字幕（v0.6.0 以来一致行为，属预期）。
- **`chapter_av_export` 全链路 + 一致性前置门 + sidechain ducking 总耗时上升**：`voice_only` 路径与 v0.6.0 持平；`full` 路径因 `sidechaincompress` + `amerge SFX` 时长上升约 5–10%（R-P5-11 范围内可接受）。

## Notes for Contributors

- **新写跨 worker chain dispatch 必须遵守 W19b commit-then-send_task 契约**：service 层显式 `await session.commit()` 后再 `send_task`；W29 voice_clone chain / W31 chapter_av_export BGM/SFX path 已示范，新 chain 必走同样路径。
- **alembic 链推到 0021，新 migration 从 0022 开始**：单 wave 一个 migration 便于回滚（D-P5-6 决策），不要一个 migration 塞多个 wave 的 schema 变更。
- **i18n 4 locale × 6 ns（common / layout / settings / notFound / commerce / auth）必须同步覆盖**：`pnpm run audit-i18n` 锁完整度；新增 ns 时同步注册到 `i18n.ts` + `audit-i18n-completeness.ts` + 4 locale 文件全部建文件。
- **5 个 P2 占位 i18n ns（compliance/formula/hook/cta/archetype）当前保持 `{}` 空对象**：未来组件真用时由对应 wave 补充翻译，audit 跳过空对象不算 missing；不要主动填充未使用的 namespace。
- **`get_current_user` 每请求 db.get 查 DB 是设计**：通过 SQLAlchemy identity map O(1) 命中同 session 内不重复 SQL；不要为了"性能"把 role 缓存进 JWT claims，避免降权延迟。
- **`/api/v1/public/*` 走 W24 ApiKey middleware scope**，**与 W32 RBAC 解耦**：第三方调用入口走 ApiKey 路径，admin 管理路径走 JWT；不要在 `public` 子树加 `require_admin`，也不要在 admin 端点加 ApiKeyMiddleware。
- **`require_admin` 加守卫粒度**：`router-level dependencies=[Depends(require_admin)]` 适合整子树（如 `/settings/api-keys/*` / `/settings/users/*`）；`per-endpoint require_admin` 适合 GET 浏览读路径要保留开放、写路径要锁的子树（如 `/llm/*` / `/commerce/projects/{id}/subtitle-styles`）。
- **`AudioMixMode` 默认 `voice_only` 兼容 W19**：调用方未传 `audio_mix_mode` 字段时行为与 v0.6.0 一致；新增 mode 必走 `_resolve_effective_audio_mix_mode` 资源缺失自动 fallback voice_only + warning 路径，不要直接抛 raise。
- **DashScope SDK 调用必须 `asyncio.to_thread`**：sync SDK 在 async 路径内不能直接调；W29 voice_clone_service 全部 `to_thread` 包裹，且 `_REGION_SWITCH_LOCK` 全局串行化避免 `base_http_api_url` 跨 region 竞态。
- **数字人路径调研产出 `plans/digital-human-research.md`**：D10 决策保留至 P5+；实装走 Wave 35+ 推荐路径（Sync Labs API 主路径 / SadTalker 次选 / 不推荐 D-ID）；不要在 P5 范围内塞 lip-sync 代码。
- **`shot.status`、runtime task status、video-readiness 三类状态术语稳定**：`shot.status ∈ {pending, ready}` 仅表"信息确认状态"；运行时状态来自任务系统（W32 RBAC 任何角色都能读自己的 task）；视频准备度独立表达；写文档不要混用。
- **`SubtitleStyle` 系统行（`project_id IS NULL`）immutable**：写路径 service 层 enforce 403；不要为了某个项目"临时"改系统行字体或颜色，正确做法是项目级覆盖 + name 同名让 resolver 自动屏蔽。
- **`VoicePack` 海外音色（en/ja/ko）走 `seed_overseas_voice_packs.py` 同管线**：禁止直接 INSERT 未经 DashScope `create_voice` 验证的 `voice_id`；幂等基于 `voice_pack.id` 已存在跳过；新增海外音色加 spec 即可。
- **`bootstrap_admin` 启动期幂等**：仅当 users 表为空才创建；不要因为"重启 db 后想重置 admin"去 DROP 表，正确做法是 `PATCH /api/v1/settings/users/{admin_id}` 改 password 或 `POST` 新建另一个 admin 后软删旧的。
